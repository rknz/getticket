GeTicket Pro - Complete Setup & Booking Guide

🪟 How to Install on Windows (Chrome, Brave, Edge, Opera)

Step 1: Download Extension ZIP or Unpack

Download Geticket-v1.0.0.zip and extract it to any folder on your PC.

📥 Download Extension ZIP (v1.0.0)
Step 2: Open Extensions Page

Paste the following URL into your Chrome address bar:

chrome://extensions/
Step 3: Enable Developer Mode & Load Unpacked

Toggle ON Developer mode in the top-right corner. Then click Load unpacked at top-left and select the extracted folder.

Step 4: Pin & Configure

Click the puzzle piece icon (🧩) on your browser toolbar and pin 📌 GeTicket Pro. Configure your route and morning schedule.

🤖 How to Install on Android (Kiwi Browser / Lemur Browser)

Step 1: Install Kiwi Browser

Install Kiwi Browser from Google Play Store. It uses the Chrome engine and runs desktop extensions natively on mobile.

Step 2: Download the ZIP

Download Geticket-v1.0.0.zip onto your Android device.

📥 Download Extension ZIP (v1.0.0)
Step 3: Install Extension in Kiwi

Tap three dots (⋮) $\rightarrow$ Extensions $\rightarrow$ Turn ON Developer mode $\rightarrow$ Tap +(from .zip / .crx / folder) and select the ZIP file.

Step 4: Open eticket.railway.gov.bd & Book

Login to your Bangladesh Railway account. Tap three-dot menu (⋮) $\rightarrow$ scroll down $\rightarrow$ GeTicket Pro Control. The floating HUD bubble will appear on the booking site!

🍎 How to Use on iPhone / iOS (Orion Browser & Safari Web App)

Method 1: Orion Browser for iOS (Native Chrome Extension Support)

Install Orion Browser by Kagi from the Apple App Store. Orion is built on WebKit and natively runs desktop Chrome extensions directly on iPhone/iPad!

  • Open Orion $\rightarrow$ Settings $\rightarrow$ Extensions $\rightarrow$ Enable Chrome Extensions.
  • Load GeTicket Pro or add from zip.
  • Visit eticket.railway.gov.bd — the extension runs and locks seats natively on your iPhone!
Method 2: Install as iPhone Web App (PWA)

Open this dashboard in Safari on your iPhone, tap the Share button (square with arrow) $\rightarrow$ tap Add to Home Screen. It creates a full-screen, standalone app on your iPhone home screen!
